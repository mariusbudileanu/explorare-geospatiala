## v3.0.0

Changes below summarize the accepted development history since `v2.0.0` (`ee0bf9aaba344042095d5d2804389b7016694d54`). Scientific baseline: `3f4ce5d2a6c4c7deea4ca8ee3fcabf5cfb01e17b`; this release-preparation patch changes documentation and metadata, not laboratory calculations.

### Educational expansion

- Retains seven academic sections, the optional learning pathway, glossary, formative checks, final project and QGIS workshops T01–T06.
- Extends Digital Companion to twenty stable laboratory identities. Eleven routes are new: L01 scale/resolution, L02 generalization, L04 measurement, L06 thematic methods, L12 Zarr, L15 raster analysis, L16 spatial statistics/MAUP, L17 networks, L18 multicriteria decisions, L19 georeferencing and L20 GIS Calculator.
- Upgrades nine v2 routes: L03 CRS, L05 classification, L07 Map Design Studio, L08 diagnostics, L09 topology, L10 interoperability, L11 Raster Styling, L13 data quality and L14 analysis. Existing URLs are retained.
- Adds RO/EN laboratory interfaces and explanations; legacy content is predominantly Romanian. Keyboard controls, responsive layouts, themes, reset, supported URL state and static fallback remain part of the laboratory contracts.

### Scientific and technical work

- Reuses shared projection/geodesic, classification, cartographic, topology, raster, expression, comparison and lifecycle services rather than parallel diagnostic calculation engines.
- Adds educational aggregation, spatial weights/Moran's I, shortest paths/reachable sets and weighted multicriteria evaluation with documented assumptions and constraints.
- Integrates the embedded ANM/EOCube Zarr snapshot and offline chunk-access model; does not introduce live cloud data acquisition.
- Integrates two fictional EPSG:3844 map sheets, seven georeferencing methods and PNG/PGW export, with separate inverse-consistency diagnostics and export protection.
- Addresses confirmed audit findings: restored controls/model agreement; reset and browser-history state; mixed historical/future temporal chunks; Hansen product-specific terminology; inverse-safety feedback; vector IF/CASE NULL handling; disconnected-site eligibility; and raster CASE NoData propagation with lazy evaluation.
- Keeps scientific algorithms, fixtures and data frozen at the accepted baseline during release preparation. Independent audits and numerical/browser regression checks provide bounded evidence, not universal certification.

### Documentation and provenance

- Prepares CFF version 3.0.0 and the verified concept DOI without inventing a version DOI or release date. Retains Marius Budileanu and the verified University of Bucharest, Faculty of Geography affiliation.
- Preserves MIT for original code, CC BY 4.0 for original educational content, and third-party licenses/permissions. Documents the qualifications attached to the owner-confirmed geo-spatial.org subset redistribution authorization.
- Keeps full external workshop datasets outside the archive; source/download/preparation instructions remain linked to the canonical registry.
