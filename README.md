# Explorare geospațială

**De la concepte clasice la GIS (QGIS)**

Un site educațional în limba română care leagă ideile clasice ale cartografiei de datele geospațiale, GIS și QGIS. Explicațiile sunt însoțite de figuri, comparații și exerciții interactive.

Proiectul se adresează în primul rând studenților care încep să lucreze cu informație geospațială, în special studenților la Geografie.

## Parcurs educațional

1. Fundamente geospațiale
2. Harta și elementele ei
3. Proiecții și sisteme de coordonate (CRS)
4. Metode de reprezentare
5. Date geospațiale
6. Analiza datelor geospațiale
7. Ateliere QGIS

## Sursa istorică

A. Năstase și D. Cernea, *Cartografie generală – manual practic*, Universitatea din București, 1974. [Publicația în Biblioteca Digitală](https://biblioteca-digitala.ro/?pub=10971-cartografie-generala).

## Ateliere QGIS și date

Atelierele T01–T06 formează o serie practică progresivă, de la alcătuirea unei hărți la lucrul cu date vectoriale și raster. Seturile de date pentru exerciții nu sunt incluse în repository. Acolo unde sunt disponibile și verificate, site-ul indică sursele originale; se aplică termenii furnizorilor respectivi.
