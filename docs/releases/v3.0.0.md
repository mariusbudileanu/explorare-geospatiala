# Explorare geospațială v3.0.0

Release-description draft for a future GitHub Release. No v3 tag, release date or version-specific DOI has yet been created. Version-specific repository links below become available only after the authorized tag is published.

## Overview

Explorare geospațială is a static educational cartography and GIS platform by Marius Budileanu, University of Bucharest, Faculty of Geography. Version 3 expands its Digital Companion into twenty interactive laboratories alongside seven academic sections and QGIS workshops T01–T06. Students can compare methods, inspect calculations and question the assumptions behind mapped results.

The optional learning pathway, learning levels, RO–EN glossary, formative checks and final project support progression without restricting access. V3 laboratory interfaces and explanations support Romanian and English; older lessons and workshops remain predominantly Romanian. The platform is not a claim that an associated textbook has already been published.

## Twenty laboratories: new and substantially enhanced

Eleven laboratory routes are introduced relative to v2.0.0:

- **L01 / L02:** scale and resolution; cartographic generalization.
- **L04 / L06:** geospatial measurement; interactive thematic methods.
- **L12 / L15:** Zarr Cloud Data Lab; Raster Analysis Workbench.
- **L16 / L17 / L18:** spatial statistics and MAUP; network accessibility; multicriteria spatial decisions.
- **L19 / L20:** georeferencing; GIS Calculator.

Nine existing v2 destinations are expanded rather than counted as newly introduced pages: **L03** Projection & CRS Lab, **L05** Classification Lab, **L07** Map Design Studio, **L08** Map Diagnostics, **L09** Topology, **L10** Formats & Interoperability, **L11** Raster Styling, **L13** Data Quality & Uncertainty and **L14** Geospatial Analysis.

Vector/raster GIS challenges, transparency and blending, existing theory and practical workshops remain available. Stable destinations and supported versioned state links are preserved. The [README laboratory inventory](https://github.com/mariusbudileanu/explorare-geospatiala/blob/v3.0.0/README.md#digital-companion--20-de-laboratoare) provides direct links.

## Scientific and technical improvements

Shared engines support projection and ellipsoidal measurement, classification, thematic encoding, topology, raster operations and expressions. Spatial statistics expose aggregation, normalization, spatial weights and MAUP assumptions. Network experiments distinguish shortest paths, distance, time, disconnection and network service areas. Multicriteria decisions expose benefit/cost normalization, effective weights, hard eligibility constraints, contributions and sensitivity.

Map Diagnostics reuses actual engine results for controlled before/after experiments. A/B comparisons, keyboard interaction, themes, responsive layouts, reset, supported URL state and lifecycle cleanup are integrated across the laboratories. Static fallback explains the content when JavaScript is unavailable; it does not reproduce every interactive computation.

Independent global audits, targeted re-audits and numerical/browser regression checks informed corrections to state restoration/history, temporal chunk explanations, Hansen metadata, inverse-transformation safety, NULL semantics, unreachable alternatives and raster CASE NoData propagation. These checks are evidence for the tested methods and fixtures, not certification of universal scientific correctness or formal WCAG compliance.

## Zarr and georeferencing scope

**L12** uses an embedded ANM/EOCube snapshot and an offline model of chunking and data access. It is not a live cloud client. The 2026 interval is incomplete; annual means retain the documented variable semantics, including mean daily precipitation rather than an annual precipitation total. Modeled layouts and transfer quantities are teaching estimates, not cloud benchmarks. Mixed chunks may contain both available historical dates and future fill values.

**L19** contains exactly two fictional maps: ZAREA at 1:10,000 and Delta Sălciilor at 1:100,000, both Stereo 70 / EPSG:3844. Seven supported transformations and PNG + PGW export are retained. Approximate inverse consistency is checked separately from fitting residuals; a small GCP residual does not guarantee reliable rectification. A PGW world file alone does not encode the CRS.

## QGIS workshops and reproducibility

T01–T06 target QGIS 3.44 LTR and link required data to official sources, documented editions, preparation steps, checkpoints and interpretation limits. English QGIS command names are explained mainly in Romanian. Complete external teaching datasets and prepared QGIS projects are not bundled. Complete end-to-end execution of every workshop in QGIS 3.44 has not been independently certified.

## Known limitations

- Synthetic networks, MAUP examples and decision alternatives are educational models, not operational routing or planning recommendations.
- Geometry, statistical and raster methods have the documented coverage and assumptions; unsupported configurations are not evidence that every such real-world geometry is invalid. No general-purpose GIS replacement is claimed.
- Hansen `lossyear = 0` means no detected loss; `datamask = 0` means no data. Positive loss-year counts are not all valid land pixels. Existing combined zero/excluded summaries and clipped analysis support limit interpretation; loss-only denominators must not be read as locality-wide loss rates.
- Rendering-dependent PNG bytes and search snippet ordering can vary with browser/font environments. Use the documented canonical build and exact-LF archive verification for strict reproduction; scientific/geometric expectations remain separate from byte hashes.
- Dataset-specific provenance qualifications, incomplete periods and modeled transfer assumptions remain visible; free access does not guarantee identical future upstream editions.
