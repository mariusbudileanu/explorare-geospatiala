Topologie

Înțelege relațiile dintre geometrii, regulile topologice și diferența dintre o geometrie invalidă și o relație incompatibilă cu modelul de date.

Relația înaintea regulii

Topologia nu spune singură ce este greșit. Modelul de date stabilește ce relații sunt permise.

Relație → regulă → eroare → context → decizie. Începem cu relațiile și construcția geometriei, în scene originale cu coordonate fixe.

Unele relații sunt simetrice

A Touch B ↔ B Touch A
A Overlap B ↔ B Overlap A

Perspectiva schimbă ordinea obiectelor, fără a schimba relația.

Altele au direcție

A Contains B ↔ B Within A
A Cover B ↔ B CoveredBy A

Aceeași scenă poate fi descrisă din perspective opuse. Pe frontieră, Cover nu înseamnă obligatoriu Contains.

Geometry Checker

Este orientat spre verificarea și repararea calității geometriei și include și unele verificări topologice: overlaps, gaps sau duplicates.

Self intersections, Duplicate nodes și Self contacts sunt exemple de verificări ale construcției geometriei.

În QGIS 3.44: Vector → Check Geometries…, cu filele Setup și Result. Este un core plugin; dacă nu este activ, verifică lista Installed din Plugin Manager.

Topology Checker

Aplică reguli topologice configurate între features și/sau layere. Include și verificări precum invalid geometries.

Instrumentele au verificări care se suprapun conceptual. Nu formează două domenii complet separate.

Activare: Plugins → Manage and Install Plugins → Installed → Topology checker. Apoi Vector → Topology checker; Configure permite configurarea regulilor.

Relație → regulă → context

O regulă topologică nu este adevăr universal. Este o condiție impusă de modelul de date. Alege întâi layerul verificat și cerința modelului; apoi configurează regula și, dacă este necesar, layerul de referință.

Diagnostic → localizare → reparare → validare

Nu este suficient să cunosc regula. Trebuie să pot identifica geometria care o încalcă și să înțeleg ce modificare ar readuce datele în starea cerută de model.

Ce trebuie să reții

  1. Topologia descrie relații între geometrii.
  2. Geometrie validă ≠ model topologic valid.
  3. Regula depinde de modelul de date.
  4. Target layer și reference layer contează.
  5. Topology Checker detectează încălcări ale regulilor configurate.
  6. Repararea cere înțelegerea intenției datelor.

Prevenție vs verificare

Topology Checker detectează situații care încalcă regulile configurate. Topological editing ajută la păstrarea limitelor comune în timpul editării: mutarea unui vertex sau segment comun poate actualiza și geometriile vecine.

În QGIS 3.44, layerele implicate trebuie să fie vizibile și în editare. Overlapping control poate preveni suprapunerea poligoanelor nou digitizate, conform configurației. Aceste instrumente de prevenție completează verificarea datelor existente.
